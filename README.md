# @letta-ai/environment-compass (Адаптация для Windows и Cloud)
Мод для Letta Code, дающий агенту представление об окружении, в котором он запущен. Мод пассивен: он не модифицирует систему, а только считывает её состояние и предоставляет эти данные агенту для принятия решений.
[🇬🇧 English version](README_EN.md)

## Отличия от оригинала (upstream)
Этот форк адаптирует оригинальный мод `environment-compass` для стабильной работы в двух режимах: **локальный бэкенд** (с оптимизацией для Windows) и **облачный агент**.
### Ключевые улучшения
#### 1. Универсальное определение директории памяти (`resolveMemoryDir`)
Оригинальный мод проверял только путь облачного агента, из-за чего не работал с локальным бэкендом. Этот форк динамически проверяет оба пути:
- `~/.letta/lc-local-backend/memfs/<agentId>/memory` — **Локальный бэкенд**
- `~/.letta/agents/<agentId>/memory` — **Облачный агент**
#### 2. Исправления для среды Windows
Добавлена полная кроссплатформенная поддержка для локальных установок на Windows:
- **Определение ОС:** Точное определение среды через `process.platform === "win32"`.
- **Поиск исполняемых файлов:** Учет `PATHEXT` при поиске (корректно находит `letta.cmd`, `letta.exe`, `letta.ps1`).
- **Определение пути установки:** Корректное получение пути к локальному пакету через переменную `%LOCALAPPDATA%\Programs\letta-code\`.
- **Проверка прав доступа:** Исправлена проверка исполняемых файлов: используется `F_OK` вместо `X_OK` (который некорректно работает в Windows).
## Установка
Установка локально:
```bash
letta install .
```
Выполните `/reload` в активных сессиях Letta, чтобы изменения вступили в силу.
## Происхождение и авторство
Этот мод является адаптацией community-разработки **Environment Compass**, изначально продемонстрированной в рамках **Letta Mod Challenge** (Letta Office Hours). Данный форк адаптирован для кроссплатформенного использования в средах **Windows (local backend)** и **Cloud**.
